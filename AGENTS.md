# Instrucciones del proyecto

- Mini Inventario es una web de inventario.
- El proyecto usa Node.js 22 y Python 3.12.
- Cada cambio debe realizarse en una rama y entregarse mediante un pull request.
- Nunca subas llaves, credenciales ni archivos `.env` al repositorio.
- Pide aprobación explícita antes de borrar datos o desplegar.
